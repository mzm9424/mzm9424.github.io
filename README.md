# Bit Trade Net (BTN)

A responsive cryptocurrency trading dashboard built with HTML, CSS, and JavaScript.

## Overview

Bit Trade Net (BTN) is a frontend-only cryptocurrency trading interface designed to demonstrate the core components of a modern trading platform. The application provides an interactive user experience with a clean, responsive design suitable for desktop and mobile devices.

The project focuses on frontend development concepts, including user interface design, state management, and responsive layouts.

## Features

- Responsive trading dashboard
- Market overview and asset displays
- Simulated account balances
- Buy and sell order interfaces
- Transaction history views
- Local data persistence using browser storage
- Mobile-friendly user experience

## Technology Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- SVG Assets
- Browser Local Storage

## Important Notice

This repository is a **simulation and educational frontend project only**.

The application does **not** connect to:

- Cryptocurrency exchanges
- Blockchain networks
- Banking systems
- Payment processors
- Real trading accounts

All displayed data, including account balances, asset prices, orders, deposits, withdrawals, and transaction records, is simulated for demonstration purposes.
