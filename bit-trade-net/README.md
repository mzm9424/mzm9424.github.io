# bit Trade net — BTN

Responsive cryptocurrency trading portal frontend built with:

- HTML5
- CSS3
- Vanilla JavaScript
- SVG
- Browser localStorage

## Important

This repository is a simulated frontend.

It does not connect to:

- cryptocurrency exchanges
- blockchain networks
- banks
- payment processors
- real wallets
- real trading accounts

Balances, prices, orders, deposits, withdrawals and transaction history are interface data stored locally in the browser.
